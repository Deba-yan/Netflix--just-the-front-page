🎬 Netflix Front Page Clone
---
📌 About the Project
--
This project is a Netflix front page clone created using HTML and CSS.
The purpose of this project was to understand how real-world websites are structured and styled, focusing on layout, responsiveness, and UI components.

🛠️ Technologies Used
----
HTML5

CSS (Flexbox, positioning, media queries)

✨ Features
----
Netflix-style landing page UI

Image/movie slider section

Language changer (English / Hindi style selector)


📚 What I Learned
----
By building this project, I learned:

How to structure a real website using HTML

How to design layouts using CSS Flexbox

How sliders work in UI design

How to create a language selection dropdown

Proper spacing, alignment, and responsiveness

Writing cleaner and more organized CSS

🎯 Project Purpose
---
Practice HTML & CSS fundamentals

Improve front-end design skills

Understand real-world UI implementation

Prepare for learning JavaScript and advanced frameworks

🚀 Future Enhancements
----
Add JavaScript for dynamic sliders

Implement login/signup functionality

Improve responsiveness and accessibility
